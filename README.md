# 11:00 PM

A short psychological horror game built for the web.

You are an office worker finishing late.
Your computer boots normally.
Then it doesn’t.

No jumpscares.
No monsters.
Just a system that doesn’t want you to leave.

⏱ Playtime: 5–10 minutes  
🎮 Genre: Psychological Horror  
🖥 Platform: Web (HTML, CSS, JavaScript)

> This game is meant to be played in one sitting.
> Closing the tab ends the experience.
